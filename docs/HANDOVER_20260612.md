## What shipped this session

- **v0.4.222/223 -- fatswap** (the original task). Crash-ordered in-place
  KERNEL8.IMG rewrite on the FAT32 boot partition; FS_FATSWAP on the fs
  endpoint; plat_blk_*_abs absolute-LBA HAL; virtio MBR parse; /bin/fatswap;
  pi_flash.py; fatswap_qemu_test.py 46/46. HW-verified warm + cold boot.
- **v0.4.224 -- eMMC integrity hardening**. Data-phase completion timeouts
  now FAIL+retry (were silent fall-throughs that drained empty FIFOs / lost
  writes under stall quanta); blk_cache evict_one won't drop dirty-on-failed-
  flush; ext2_pwrite propagates write errors. /proc/cachestats emmc_timeout_*.
- **v0.4.225 -- THE big find: ext2 image-builder off-by-one**. The deploy
  "corruption scare" was NOT network/eMMC: scripts/ext2/builder.py laid block
  group g>0 at g*bpg while the kernel allocator uses first_data_block+g*bpg,
  so the last block of each group aliased the next group's BLOCK BITMAP ->
  allocator handed a bitmap block out as file data -> bitmap writes clobbered
  the file with 0xFF. Only bit files >~960KB (group 10+). Fixed builder +
  one-time ext2 reflash. netrx_repro 0/24 (was 2-3/8). Reusable lesson:
  feedback_ext2_group_layout memory.
- **v0.4.226 -- netconsole RX profiling (honest no-op)**. Coalesced TCP
  window-reopen ACKs (9x fewer, confirmed) but HW throughput UNCHANGED -> ACK
  TX wasn't the bottleneck. Kept the change + counter. Also kept from the
  hunt: inbound TCP checksum verify, SPSC rx-ring acquire barrier,
  /proc/netstat counters + drop-Nth fault knob, netrx_qemu_test.py.

## Gotchas carried forward

- Stall quanta make HW timing/throughput measurements unreliable -- failures
  at 32s multiples (36/68/191s) are quanta, not your bug. Drive netconsole
  gently; pi_flash already retries.
- Always verify a deploy via /proc/version banner (build N = ninja's N-1).
- Both trees after shared-code changes: ninja -C build-04 AND build-rpi4.
- QEMU hides HW-only bugs (eMMC PIO, GENET TX latency, the quanta, pipe-SHM
  cache coherency). Verify storage/net correctness on HW.
